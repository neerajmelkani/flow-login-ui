# Flow Login UI 

A modern and responsive login page built using HTML, CSS, and JavaScript.

## Features

- Modern Glassmorphism Design
- Dark Premium Theme
- Animated Neon Background
- Show / Hide Password
- Remember Me Option
- Forgot Password Link
- Login Button Loading Animation
- Responsive Layout
- Interactive UI Elements
- Clean and Beginner-Friendly Code

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## Project Structure

```bash
FlowLoginUI/

```
